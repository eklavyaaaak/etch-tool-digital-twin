Built as a portfolio project. The chamber geometry is generic and the physics is simplified: pump-down is exponential decay toward base pressure, a leak adds a constant inflow, and process pressure is set by gas flow against throttle valve conductance. The tool detects and escalates faults. It never repairs them itself.
